# Housemate
 Housemate is a modern, student-centered house hunting platform specifically designed to solve the real struggles JKUAT students face when trying to find safe, affordable, and convenient accommodation. The platform exists because the current house-hunting methods — word of mouth, walking around estates, and unreliable online listings — are outdated, time-consuming, and often frustrating. Housemate not only links you with the caretaker, it allows you to book visits, check visits and above all view the existing properties using Augmented Reality. It is a centralized website for viewing verified, up-to-date listings with high-quality images and property descriptions. It employs the use of Augmented Reality (AR) previews — so students can "walk through" rooms virtually before ever stepping outside.Real-time vacancy updates, location filters, and user reviews. A smooth, user-friendly experience designed with student needs in mind.
